## 一、原始产品文档（用户提供）

Link World产品文档

### 1. 产品概述
Link World 是基于区块链的全球去中心化通信平台，连接运营商与 Web3 用户，提供跨境流量及通话服务。定位：无需KYC、钱包即身份、提交保证金获取流量卡、全球无限制转网。

### 2. 目标用户
- 数字游民、跨境工作者、短期旅行者、留学生
- Web3 / 加密用户（偏好无 KYC、链上结算）
- 有跨境灵活通信需求的全球用户

### 3. 核心痛点
- 跨境换网麻烦
- 传统付费需求高，门槛高

### 4. 核心功能需求

#### 4.1 提交保证金得流量卡
- 用户注册时需要连接钱包并提供邮箱
- 存保证金获得NFT卡，销毁后获取流量使用以及通话
- 用户预存基础保证金，从10u起不设限制，保证金锁仓一个月即可获得流量卡NFT，流量额度随保证金金额变动
- 用户预存保证金，锁仓一定周期，可获得不同价值的NFT卡，销毁立即生效，销毁后有效期30天，过期失效

#### 4.2 自动转网
- 用户提交保证金后可在平台上任意选择目的地国家或地区运营商的流量服务，无需线下购买
- Anytime anyway, 提供24H服务

#### 4.3 去中心化身份
- 连接的钱包支持binance、okx等交易所钱包。加密钱包用户提交本地号码即可使用

#### 4.4 流量卡NFT
- NFT卡在用户提交保证金并锁仓后立即发放给用户，锁仓期未到时间前用户无提取权限
- 用户的NFT卡可逐月积累，用户间不可二次转卖
- 便捷转网（跨境使用）：用户持有NFT卡可以在跨国跨境时使用，无需线下购买手机卡

#### 4.5 连接运营商功能
- 平台对接运营商：用户可在使用完流量卡后直接在平台上选择对应国家的运营商并购买通讯服务，使用钱包付款，更便捷，更迅速
- 手续费1.5%：用户购买运营商的流量及通讯服务时需要支付购买金额的1.5%作为手续费，在支付页面显示

#### 4.6 实体通讯卡放送问题
用户在使用需SIM卡的设备时可以选择线下\邮寄等方式领取目的地国家的SIM卡，后续我们将推出全球通的SIM卡，便捷用户
